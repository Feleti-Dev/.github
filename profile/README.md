# Feleti Organization

**Feleti** — белорусская производственная компания с 16-летним опытом работы в сфере пищевой промышленности. Специализируемся на инженерных разработках, производстве и сервисном обслуживании оборудования для предприятий пищевой промышленности. Наша миссия — строить долгосрочные отношения с клиентами на основе доверия и взаимопонимания, находить уникальные и эффективные решения для реализации бизнес-целей каждого клиента.

GitHub-организация **Feleti-Dev** объединяет технические решения, внутренние инструменты разработки и проекты с открытым исходным кодом, которые помогают нам автоматизировать бизнес-процессы, оптимизировать производство и создавать современные цифровые продукты для пищевой промышленности.

## Направления деятельности

Мы работаем с широким спектром отраслей пищевой промышленности, обеспечивая комплексный подход к автоматизации и механизации производственных процессов.

**Мясная промышленность:** Оборудование для убоя и первичной переработки скота, линии мясопереработки, автоматизированные участки разделки и упаковки. Наши решения помогают повысить производительность и соблюсти санитарные нормы на каждом этапе производства.

**Молочная промышленность:** Оборудование для переработки молока, производства сыров, масла и кисломолочной продукции. Комплексные линии, отвечающие современным стандартам качества и безопасности пищевых продуктов.

**Хлебопекарная и кондитерская отрасли:** Автоматизированные линии для производства хлебобулочных и кондитерских изделий, оборудование для тестоприготовления, выпечки и упаковки готовой продукции.

**Розничная торговля и HoReCa:** Оборудование для магазинов, ресторанов, кафе и гостиниц, включая линии раздачи, витрины и специализированное оборудование для общепита.

**Рыбопереработка и переработка овощей:** Линии для обработки рыбы, морепродуктов, овощей, фруктов и ягод с учётом специфики каждого вида сырья.

## Услуги

**Инженерные разработки:** Проектирование и разработка индивидуальных решений под конкретные задачи заказчика. Наши инженеры погружаются в технологические процессы клиента, чтобы предложить оптимальный вариант автоматизации.

**Производство оборудования:** Собственное производство площадью 5 000 квадратных метров позволяет контролировать качество на каждом этапе изготовления и обеспечивать гибкость при выполнении заказов любой сложности.

**Сервисное обслуживание:** Полный цикл сервисной поддержки на всем жизненном цикле продукта. Технический аудит, ремонт, модернизация и регулярное техническое обслуживание оборудования.
